## Changelog

For every functional change, add under the current `-dev` version
section of `docs/changelog.md` a one-line entry, from the user
perspective, tagged `[Added]`, `[Changed]` or `[Fixed]`, and
referencing the relevant feature file or issue; the newest entry comes
first. The changelog is for users: it does not record internal
refactoring or dev-only changes.
